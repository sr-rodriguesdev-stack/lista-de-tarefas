# Projeto de Estudos

## Ciclo de Vida de uma Requisição HTTP

### Sobre o Projeto

Este projeto tem como objetivo estudar e compreender o funcionamento de uma requisição HTTP desde o momento em que o usuário realiza uma ação no navegador até o recebimento e a renderização da resposta pelo cliente.

### Objetivos

- Entender o papel do protocolo HTTP na comunicação entre cliente e servidor.
- Compreender as etapas envolvidas no ciclo de vida de uma requisição.
- Identificar como DNS, TCP, TLS e HTTP trabalham em conjunto.
- Analisar o processamento das requisições em servidores web.
- Entender o retorno das respostas e sua renderização no navegador.

### Conteúdos Estudados

- Conceitos de HTTP e HTTPS
- Resolução de DNS
- Estabelecimento de conexão TCP
- Requisições e respostas HTTP
- Métodos HTTP
- Códigos de status
- Processamento no servidor
- Integração com banco de dados
- Renderização no navegador

### Metodologia

O estudo foi realizado por meio de aulas teóricas, análise de exemplos práticos e observação de requisições reais utilizando as ferramentas de desenvolvedor do navegador.

### Resultados Esperados

Ao final do projeto, espera-se ser capaz de descrever todo o fluxo de uma requisição HTTP, identificar possíveis pontos de falha e compreender como aplicações web modernas se comunicam pela internet.

### Conclusão

O conhecimento do ciclo de vida de uma requisição HTTP é fundamental para o desenvolvimento web, pois permite entender como ocorre a comunicação entre clientes e servidores, facilitando a criação, manutenção e depuração de aplicações.
